    Best swaps

    Data: the planning run of Thu 11/5 and the NBA schedule. Val: the per-game Val of the Free agents page. A player with no Val gets a Val from his projection, with the proj tag. Each day, the core players start in Val order, highest first, in 6 slots. Value started: the sum of the Val of each started game, with 10% more on a light night (6 or fewer NBA games). Starts lost: core games that sit because the lineup is full. Open slots: the empty slots that a stream player can fill. A player with the R tag rests on the second night of each back-to-back. The R switch does not change the rest list. Adds: the value started of the core with the player minus without him. Best swaps: the schedule gain is the value gain minus (Val in − Val out) × the starts of the player out. Save keeps the core in this browser.
