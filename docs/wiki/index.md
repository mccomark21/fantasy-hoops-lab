# Project wiki

This wiki records the history and the decisions of Fantasy Hoops Lab. It does not explain how a tool works. For a tool, read `docs/<tool>/README.md`. For the shared terms, read the [glossary](../glossary.md).

Each page records dated facts. A claim about code cites a commit as `mccomark21/fantasy-hoops-lab@<sha>`.
